# Escaneo-e-Impresi-n-3D-de-Craneos
Proyecto enfocado en el escaneo, digitalización y reproducción mediante impresión 3D de los cráneos de un guacamayo y un chimpancé. Los modelos obtenidos permiten analizar su estructura ósea y realizar comparaciones morfológicas entre especies.
